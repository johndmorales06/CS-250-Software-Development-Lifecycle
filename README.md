# CS 250 – Software Development Lifecycle

## Project Overview

This repository contains my Sprint Review and Retrospective from CS 250 at Southern New Hampshire University. Throughout this course, I learned about Agile and Scrum practices and how they help software development teams organize their work, communicate, and respond to changes. This project helped me better understand the responsibilities of different Scrum roles and the importance of working together to deliver software that meets user needs.

## How Do I Interpret User Needs and Implement Them Into a Program?

I start by understanding what the user wants the program to accomplish and what problems it should solve. Creating user stories helps break down those needs into smaller tasks that developers can understand and work on. User stories also help explain why a feature is important from the user's perspective. During this course, I learned how to use user stories and acceptance criteria to keep development focused on what the user actually needs.

## How Do I Approach Developing Programs?

When developing programs, I like to break larger problems into smaller steps so they are easier to manage and troubleshoot. I also believe testing throughout development is important because it helps catch problems early. In the future, I hope to use Agile practices such as sprint planning, daily Scrum meetings, sprint reviews, and retrospectives. These practices can help me stay organized, track progress, and make improvements throughout the development process instead of waiting until the end.

## What Does It Mean to Be a Good Team Member in Software Development?

Being a good team member means communicating clearly, being dependable, and respecting other people's ideas. Software development involves different roles working toward the same goal, so teamwork is important. I believe a good team member should be willing to ask questions, help others when needed, and accept feedback. Throughout this course, I learned that communication and collaboration can make a big difference in how successfully a team completes a project.

## Course Reflection

Overall, CS 250 helped me understand how Agile and Scrum are used in software development. I learned how user stories, Scrum roles, and sprint activities help teams stay focused and organized. These are skills I plan to continue developing as I work toward becoming a software engineer.
